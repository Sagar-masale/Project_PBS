# PBS Jewellers

A full-stack jewellery e-commerce web application built using the MERN stack. The platform provides users with a modern online jewellery shopping experience along with a complete admin dashboard for managing products, orders, customers, authentication, and inventory.

---

# Live Demo

Frontend Live Link: https://pbsjewellers.vercel.app/

---

# Project Overview

PBS Jewellers is designed to simulate a real-world jewellery shopping platform where customers can browse products, view detailed product information, add items to cart or wishlist, place orders, and securely authenticate using email/password and OTP verification.

The project also includes an admin panel for managing jewellery products, tracking orders, updating inventory, and monitoring customer activity.
